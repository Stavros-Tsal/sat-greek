1Adding and subtracting polynomials

Remember
  • Remove brackets first: a minus sign in front of a bracket changes the sign of every term inside.
  • Then collect like terms (same variables with the same powers).

Level 1 · Starter

  1. Simplify: (3x + 5) + (2x − 7)
    Answer with full solution
    1. Remove the brackets (a plus sign in front changes nothing, a minus sign changes every sign inside):
      3x + 5 + 2x − 7
    2. Collect the like terms (add the coefficients of the same power):
      x: 3 + 2 = 5
      constant terms: 5 + (−7) = −2
    (3x + 5) + (2x − 7) = 5x − 2
  2. Simplify: (4a − 3) − (a + 2)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      −(a + 2)
      = −a − 2 (minus in front: every sign changes)
    2. Write all the parts one after the other, with no brackets left:
      4a − 3 − a − 2
    3. Collect the like terms (add the coefficients of the same power):
      a: 4 + (−1) = 3
      constant terms: −3 + (−2) = −5
    (4a − 3) − (a + 2) = 3a − 5
  3. Simplify: (x2 + 3x) + (2x2 − x)
    Answer with full solution
    1. Remove the brackets (a plus sign in front changes nothing, a minus sign changes every sign inside):
      x2 + 3x + 2x2 − x
    2. Collect the like terms (add the coefficients of the same power):
      x2: 1 + 2 = 3
      x: 3 + (−1) = 2
    (x2 + 3x) + (2x2 − x) = 3x2 + 2x
  4. Simplify: (5y2 − 2y + 1) + (y2 + 4y − 6)
    Answer with full solution
    1. Remove the brackets (a plus sign in front changes nothing, a minus sign changes every sign inside):
      5y2 − 2y + 1 + y2 + 4y − 6
    2. Collect the like terms (add the coefficients of the same power):
      y2: 5 + 1 = 6
      y: −2 + 4 = 2
      constant terms: 1 + (−6) = −5
    (5y2 − 2y + 1) + (y2 + 4y − 6) = 6y2 + 2y − 5

Level 2 · Core

  1. Simplify: (2x2 − 3x + 4) − (x2 − 5x + 9)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      −(x2 − 5x + 9)
      = −x2 + 5x − 9 (minus in front: every sign changes)
    2. Write all the parts one after the other, with no brackets left:
      2x2 − 3x + 4 − x2 + 5x − 9
    3. Collect the like terms (add the coefficients of the same power):
      x2: 2 + (−1) = 1
      x: −3 + 5 = 2
      constant terms: 4 + (−9) = −5
    (2x2 − 3x + 4) − (x2 − 5x + 9) = x2 + 2x − 5
  2. Simplify: (3a2b − 2ab + b2) + (a2b + 5ab − 4b2)
    Answer with full solution
    1. Remove the brackets (a plus sign in front changes nothing, a minus sign changes every sign inside):
      3a2b − 2ab + b2 + a2b + 5ab − 4b2
    2. Collect the like terms (add the coefficients of the same power):
      a2b: 3 + 1 = 4
      ab: −2 + 5 = 3
      b2: 1 + (−4) = −3
    (3a2b − 2ab + b2) + (a2b + 5ab − 4b2) = 4a2b + 3ab − 3b2
  3. Simplify: 5x − (2x − (3x − 4))
    Answer with full solution
    5x − (2x − (3x − 4))
    1. Start with the innermost bracket. Minus in front: −(3x − 4) = −3x + 4
      = 5x − (2x − 3x + 4)
    2. Collect inside the bracket: 2x − 3x + 4 = −x + 4
      = 5x − (−x + 4)
    3. Minus in front of the bracket: change both signs
      = 5x + x − 4
    4. Collect like terms: 5x + x = 6x
      = 6x − 4
    5x − (2x − (3x − 4)) = 6x − 4
  4. Simplify: (x3 − 2x2 + x − 1) − (2x3 + x2 − 3x + 5)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      −(2x3 + x2 − 3x + 5)
      = −2x3 − x2 + 3x − 5 (minus in front: every sign changes)
    2. Write all the parts one after the other, with no brackets left:
      x3 − 2x2 + x − 1 − 2x3 − x2 + 3x − 5
    3. Collect the like terms (add the coefficients of the same power):
      x3: 1 + (−2) = −1
      x2: −2 + (−1) = −3
      x: 1 + 3 = 4
      constant terms: −1 + (−5) = −6
    (x3 − 2x2 + x − 1) − (2x3 + x2 − 3x + 5) = −x3 − 3x2 + 4x − 6

Level 3 · Advanced

  1. Simplify: 3(2x − 1) − 2(x2 − x + 4) + x(x − 3)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      3·(2x − 1)
      = (3)·(2x) + (3)·(−1)
      = 6x − 3
      (−2)·(x2 − x + 4)
      = (−2)·(x2) + (−2)·(−x) + (−2)·(4)
      = −2x2 + 2x − 8
      x·(x − 3)
      = (x)·(x) + (x)·(−3)
      = x2 − 3x
    2. Write all the parts one after the other, with no brackets left:
      6x − 3 − 2x2 + 2x − 8 + x2 − 3x
    3. Collect the like terms (add the coefficients of the same power):
      x2: −2 + 1 = −1
      x: 6 + 2 + (−3) = 5
      constant terms: −3 + (−8) = −11
    3(2x − 1) − 2(x2 − x + 4) + x(x − 3) = −x2 + 5x − 11
  2. Simplify: ((1/2)x2 − (2/3)x + 1) + ((3/2)x2 + (5/3)x − 4)
    Answer with full solution
    1. Remove the brackets (a plus sign in front changes nothing, a minus sign changes every sign inside):
      x2/2 − 2x/3 + 1 + 3x2/2 + 5x/3 − 4
    2. Collect the like terms (add the coefficients of the same power):
      x2: 1/2 + 3/2 = 2
      x: −2/3 + 5/3 = 1
      constant terms: 1 + (−4) = −3
    ((1/2)x2 − (2/3)x + 1) + ((3/2)x2 + (5/3)x − 4) = 2x2 + x − 3
  3. Simplify: 7 − (x2 − (3x − (x2 − 2x)))
    Answer with full solution
    7 − (x2 − (3x − (x2 − 2x)))
    1. Innermost bracket: −(x² − 2x) = −x² + 2x
      = 7 − (x2 − (3x − x2 + 2x))
    2. Collect inside: 3x + 2x = 5x
      = 7 − (x2 − (−x2 + 5x))
    3. Next bracket, minus in front: change the signs of −x² + 5x
      = 7 − (x2 + x2 − 5x)
    4. Collect inside: x² + x² = 2x²
      = 7 − (2x2 − 5x)
    5. Last bracket, minus in front: change the signs
      = 7 − 2x2 + 5x
    7 − (x2 − (3x − (x2 − 2x))) = −2x2 + 5x + 7
  4. Simplify: 2(x2 − xy + y2) − 3(x2 + xy − y2) + (x − y)2
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      2·(x2 − xy + y2)
      = (2)·(x2) + (2)·(−xy) + (2)·(y2)
      = 2x2 − 2xy + 2y2
      (−3)·(x2 + xy − y2)
      = (−3)·(x2) + (−3)·(xy) + (−3)·(−y2)
      = −3x2 − 3xy + 3y2
      (x − y)(x − y)
      = (x)·(x) + (x)·(−y) + (−y)·(x) + (−y)·(−y)
      = x2 − xy − xy + y2
      = x2 − 2xy + y2
    2. Write all the parts one after the other, with no brackets left:
      2x2 − 2xy + 2y2 − 3x2 − 3xy + 3y2 + x2 − 2xy + y2
    3. Collect the like terms (add the coefficients of the same power):
      x2: 2 + (−3) + 1 = 0 (cancels out)
      xy: −2 + (−3) + (−2) = −7
      y2: 2 + 3 + 1 = 6
    2(x2 − xy + y2) − 3(x2 + xy − y2) + (x − y)2 = −7xy + 6y2
  5. Simplify (the result may surprise you): (x + 2)2 + (x − 2)2 − 2(x2 + 4)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      (x + 2)(x + 2)
      = (x)·(x) + (x)·(2) + (2)·(x) + (2)·(2)
      = x2 + 2x + 2x + 4
      = x2 + 4x + 4
      (x − 2)(x − 2)
      = (x)·(x) + (x)·(−2) + (−2)·(x) + (−2)·(−2)
      = x2 − 2x − 2x + 4
      = x2 − 4x + 4
      (−2)·(x2 + 4)
      = (−2)·(x2) + (−2)·(4)
      = −2x2 − 8
    2. Write all the parts one after the other, with no brackets left:
      x2 + 4x + 4 + x2 − 4x + 4 − 2x2 − 8
    3. Collect the like terms (add the coefficients of the same power):
      x2: 1 + 1 + (−2) = 0 (cancels out)
      x: 4 + (−4) = 0 (cancels out)
      constant terms: 4 + 4 + (−8) = 0 (cancels out)
    (x + 2)2 + (x − 2)2 − 2(x2 + 4) = 0
  6. Simplify (the result may surprise you): (a + b)(a − b) + (b + c)(b − c) + (c + a)(c − a)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      (a + b)(a − b)
      = (a)·(a) + (a)·(−b) + (b)·(a) + (b)·(−b)
      = a2 − ab + ab − b2
      = a2 − b2
      (b + c)(b − c)
      = (b)·(b) + (b)·(−c) + (c)·(b) + (c)·(−c)
      = b2 − bc + bc − c2
      = b2 − c2
      (a + c)(−a + c)
      = (a)·(−a) + (a)·(c) + (c)·(−a) + (c)·(c)
      = −a2 + ac − ac + c2
      = −a2 + c2
    2. Write all the parts one after the other, with no brackets left:
      a2 − b2 + b2 − c2 − a2 + c2
    3. Collect the like terms (add the coefficients of the same power):
      a2: 1 + (−1) = 0 (cancels out)
      b2: −1 + 1 = 0 (cancels out)
      c2: −1 + 1 = 0 (cancels out)
    (a + b)(a − b) + (b + c)(b − c) + (c + a)(c − a) = 0
  7. Simplify: 3x2y − (2xy2 − (x2y − 4xy2))
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      −(−x2y + 6xy2)
      = x2y − 6xy2 (minus in front: every sign changes)
    2. Write all the parts one after the other, with no brackets left:
      3x2y + x2y − 6xy2
    3. Collect the like terms (add the coefficients of the same power):
      x2y: 3 + 1 = 4
      xy2: −6 (only one term)
    3x2y − (2xy2 − (x2y − 4xy2)) = 4x2y − 6xy2
  8. Simplify: (2x − 3)(x + 1) − (x − 2)(2x + 5) + 3(x − 1)2
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      (2x − 3)(x + 1)
      = (2x)·(x) + (2x)·(1) + (−3)·(x) + (−3)·(1)
      = 2x2 + 2x − 3x − 3
      = 2x2 − x − 3
      (x − 2)(2x + 5)
      = (x)·(2x) + (x)·(5) + (−2)·(2x) + (−2)·(5)
      = 2x2 + 5x − 4x − 10
      = 2x2 + x − 10
      −(2x2 + x − 10)
      = −2x2 − x + 10 (minus in front: every sign changes)
      (x − 1)(x − 1)
      = (x)·(x) + (x)·(−1) + (−1)·(x) + (−1)·(−1)
      = x2 − x − x + 1
      = x2 − 2x + 1
      3·(x2 − 2x + 1)
      = (3)·(x2) + (3)·(−2x) + (3)·(1)
      = 3x2 − 6x + 3
    2. Write all the parts one after the other, with no brackets left:
      2x2 − x − 3 − 2x2 − x + 10 + 3x2 − 6x + 3
    3. Collect the like terms (add the coefficients of the same power):
      x2: 2 + (−2) + 3 = 3
      x: −1 + (−1) + (−6) = −8
      constant terms: −3 + 10 + 3 = 10
    (2x − 3)(x + 1) − (x − 2)(2x + 5) + 3(x − 1)2 = 3x2 − 8x + 10

2Multiplying polynomials

Remember
  • Monomial × polynomial: multiply the monomial by each term (distributive property).
  • Polynomial × polynomial: multiply every term of the first by every term of the second, then collect like terms.
  • Powers: xm · xn = xm+n.

Level 1 · Starter

  1. Expand and simplify: 3x(2x − 5)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      3x·(2x − 5)
      = (3x)·(2x) + (3x)·(−5)
      = 6x2 − 15x
    3x(2x − 5) = 6x2 − 15x
  2. Expand and simplify: −2a(a2 − 3a + 4)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (−2a)·(a2 − 3a + 4)
      = (−2a)·(a2) + (−2a)·(−3a) + (−2a)·(4)
      = −2a3 + 6a2 − 8a
    −2a(a2 − 3a + 4) = −2a3 + 6a2 − 8a
  3. Expand and simplify: (x + 2)(x + 5)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x + 2)(x + 5)
      = (x)·(x) + (x)·(5) + (2)·(x) + (2)·(5)
      = x2 + 5x + 2x + 10
      = x2 + 7x + 10
    (x + 2)(x + 5) = x2 + 7x + 10
  4. Expand and simplify: (x − 3)(x + 4)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x − 3)(x + 4)
      = (x)·(x) + (x)·(4) + (−3)·(x) + (−3)·(4)
      = x2 + 4x − 3x − 12
      = x2 + x − 12
    (x − 3)(x + 4) = x2 + x − 12

Level 2 · Core

  1. Expand and simplify: (2x − 3)(3x + 5)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (2x − 3)(3x + 5)
      = (2x)·(3x) + (2x)·(5) + (−3)·(3x) + (−3)·(5)
      = 6x2 + 10x − 9x − 15
      = 6x2 + x − 15
    (2x − 3)(3x + 5) = 6x2 + x − 15
  2. Expand and simplify: (x2 + x − 1)(x + 2)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x2 + x − 1)(x + 2)
      = (x2)·(x) + (x2)·(2) + (x)·(x) + (x)·(2) + (−1)·(x) + (−1)·(2)
      = x3 + 2x2 + x2 + 2x − x − 2
      = x3 + 3x2 + x − 2
    (x2 + x − 1)(x + 2) = x3 + 3x2 + x − 2
  3. Expand and simplify: (2x2 − x + 3)(x − 4)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (2x2 − x + 3)(x − 4)
      = (2x2)·(x) + (2x2)·(−4) + (−x)·(x) + (−x)·(−4) + (3)·(x) + (3)·(−4)
      = 2x3 − 8x2 − x2 + 4x + 3x − 12
      = 2x3 − 9x2 + 7x − 12
    (2x2 − x + 3)(x − 4) = 2x3 − 9x2 + 7x − 12
  4. Expand and simplify: (x + 1)(x − 1)(x2 + 1)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x + 1)(x − 1)
      = (x)·(x) + (x)·(−1) + (1)·(x) + (1)·(−1)
      = x2 − x + x − 1
      = x2 − 1
      (x2 − 1)(x2 + 1)
      = (x2)·(x2) + (x2)·(1) + (−1)·(x2) + (−1)·(1)
      = x4 + x2 − x2 − 1
      = x4 − 1
    (x + 1)(x − 1)(x2 + 1) = x4 − 1

Level 3 · Advanced

  1. Expand and simplify: (x2 − 2x + 3)(x2 + 2x − 1)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x2 − 2x + 3)(x2 + 2x − 1)
      = (x2)·(x2) + (x2)·(2x) + (x2)·(−1) + (−2x)·(x2) + (−2x)·(2x) + (−2x)·(−1) + (3)·(x2) + (3)·(2x) + (3)·(−1)
      = x4 + 2x3 − x2 − 2x3 − 4x2 + 2x + 3x2 + 6x − 3
      = x4 − 2x2 + 8x − 3
    (x2 − 2x + 3)(x2 + 2x − 1) = x4 − 2x2 + 8x − 3
  2. Expand and simplify: (x + 1)(x + 2)(x + 3)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x + 1)(x + 2)
      = (x)·(x) + (x)·(2) + (1)·(x) + (1)·(2)
      = x2 + 2x + x + 2
      = x2 + 3x + 2
      (x2 + 3x + 2)(x + 3)
      = (x2)·(x) + (x2)·(3) + (3x)·(x) + (3x)·(3) + (2)·(x) + (2)·(3)
      = x3 + 3x2 + 3x2 + 9x + 2x + 6
      = x3 + 6x2 + 11x + 6
    (x + 1)(x + 2)(x + 3) = x3 + 6x2 + 11x + 6
  3. Expand and simplify: (2x + y)(x − 3y) − (x − y)2
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      (2x + y)(x − 3y)
      = (2x)·(x) + (2x)·(−3y) + (y)·(x) + (y)·(−3y)
      = 2x2 − 6xy + xy − 3y2
      = 2x2 − 5xy − 3y2
      (x − y)(x − y)
      = (x)·(x) + (x)·(−y) + (−y)·(x) + (−y)·(−y)
      = x2 − xy − xy + y2
      = x2 − 2xy + y2
      −(x2 − 2xy + y2)
      = −x2 + 2xy − y2 (minus in front: every sign changes)
    2. Write all the parts one after the other, with no brackets left:
      2x2 − 5xy − 3y2 − x2 + 2xy − y2
    3. Collect the like terms (add the coefficients of the same power):
      x2: 2 + (−1) = 1
      xy: −5 + 2 = −3
      y2: −3 + (−1) = −4
    (2x + y)(x − 3y) − (x − y)2 = x2 − 3xy − 4y2
  4. Expand and simplify: (a + b − c)(a − b + c)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (a + b − c)(a − b + c)
      = (a)·(a) + (a)·(−b) + (a)·(c) + (b)·(a) + (b)·(−b) + (b)·(c) + (−c)·(a) + (−c)·(−b) + (−c)·(c)
      = a2 − ab + ac + ab − b2 + bc − ac + bc − c2
      = a2 − b2 + 2bc − c2
    (a + b − c)(a − b + c) = a2 − b2 + 2bc − c2
  5. Expand and simplify: (x2 + x + 1)(x2 − x + 1)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x2 + x + 1)(x2 − x + 1)
      = (x2)·(x2) + (x2)·(−x) + (x2)·(1) + (x)·(x2) + (x)·(−x) + (x)·(1) + (1)·(x2) + (1)·(−x) + (1)·(1)
      = x4 − x3 + x2 + x3 − x2 + x + x2 − x + 1
      = x4 + x2 + 1
    (x2 + x + 1)(x2 − x + 1) = x4 + x2 + 1
  6. Expand and simplify: (x − 1)(x + 1)(x2 + 1)(x4 + 1)
    Answer with full solution
    1. Multiply each term of one factor by each term of the other:
      (x − 1)(x + 1)
      = (x)·(x) + (x)·(1) + (−1)·(x) + (−1)·(1)
      = x2 + x − x − 1
      = x2 − 1
      (x2 − 1)(x2 + 1)
      = (x2)·(x2) + (x2)·(1) + (−1)·(x2) + (−1)·(1)
      = x4 + x2 − x2 − 1
      = x4 − 1
      (x4 − 1)(x4 + 1)
      = (x4)·(x4) + (x4)·(1) + (−1)·(x4) + (−1)·(1)
      = x8 + x4 − x4 − 1
      = x8 − 1
    (x − 1)(x + 1)(x2 + 1)(x4 + 1) = x8 − 1
  7. Expand and simplify: (2x − 1)(x2 + 3x − 2) − (x + 1)(2x2 + x − 3)
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      (2x − 1)(x2 + 3x − 2)
      = (2x)·(x2) + (2x)·(3x) + (2x)·(−2) + (−1)·(x2) + (−1)·(3x) + (−1)·(−2)
      = 2x3 + 6x2 − 4x − x2 − 3x + 2
      = 2x3 + 5x2 − 7x + 2
      (x + 1)(2x2 + x − 3)
      = (x)·(2x2) + (x)·(x) + (x)·(−3) + (1)·(2x2) + (1)·(x) + (1)·(−3)
      = 2x3 + x2 − 3x + 2x2 + x − 3
      = 2x3 + 3x2 − 2x − 3
      −(2x3 + 3x2 − 2x − 3)
      = −2x3 − 3x2 + 2x + 3 (minus in front: every sign changes)
    2. Write all the parts one after the other, with no brackets left:
      2x3 + 5x2 − 7x + 2 − 2x3 − 3x2 + 2x + 3
    3. Collect the like terms (add the coefficients of the same power):
      x3: 2 + (−2) = 0 (cancels out)
      x2: 5 + (−3) = 2
      x: −7 + 2 = −5
      constant terms: 2 + 3 = 5
    (2x − 1)(x2 + 3x − 2) − (x + 1)(2x2 + x − 3) = 2x2 − 5x + 5
  8. Expand and simplify: (x + 1)2(x − 1)2 − (x2 + 1)2
    Answer with full solution
    1. Work out each part separately (multiply out; a bracket with a minus in front changes every sign inside):
      (x + 1)(x + 1)
      = (x)·(x) + (x)·(1) + (1)·(x) + (1)·(1)
      = x2 + x + x + 1
      = x2 + 2x + 1
      (x2 + 2x + 1)(x − 1)

      = x3 − x2 + 2x2 − 2x + x − 1

      = x4 − x3 + x3 − x2 − x2 + x − x + 1

      −(x4 + 2x2 + 1)

    2. Write all the parts one after the other, with no brackets left:
      x4 − 2x2 + 1 − x4 − 2x2 − 1

      x4: 1 + (−1) = 0 (cancels out)
      x2: −2 + (−2) = −4
      constant terms: 1 + (−1) = 0 (cancels out)
    (x + 1)2(x − 1)2 − (x2 + 1)2 = −4x2
  9. Expand and simplify: (x − 2)(x2 + 2x + 4) − (x + 1)(x2 − x + 1)
    Answer with full solution

      (x − 2)(x2 + 2x + 4)

4Polynomials with unknown coefficients

Remember
  • Two polynomials are equal when the coefficients of the same powers are equal. Expand, then compare power by power: x³ with x³, x² with x², x with x, constant with constant.
  • A polynomial has degree d when the coefficient of xd is not zero and all higher coefficients are zero.
  • Always check the equation you did not use: it should hold with the values you found.

Level 1 · Starter

  1. Let P(x) = ax2 + bx + 3 and Q(x) = 2x2 − x + c. If P(x) − Q(x) = x2 + 5x − 2, find a, b and c.
    Answer with full solution
    1. Write P(x) − Q(x). The minus in front of Q(x) changes every sign inside it:
      (ax2 + bx + 3) − (2x2 − x + c)
      = ax2 + bx + 3 − 2x2 + x − c
    2. Collect the like terms (same power of x):
      = (a − 2)x2 + (b + 1)x + (3 − c)
    3. Two polynomials are equal when the coefficients of the same powers are equal. Compare with x2 + 5x − 2:
      x2: a − 2 = 1 → a = 3
      x: b + 1 = 5 → b = 4
      constant: 3 − c = −2 → c = 5
    4. Check:
      (3 − 2)x2 + (4 + 1)x + (3 − 5) = x2 + 5x − 2 ✓
    a = 3, b = 4, c = 5
  2. Let P(x) = 3x3 + ax2 − 5x + 2 and Q(x) = bx3 − 4x2 + cx − 1. If P(x) + Q(x) = 5x3 + 2x2 + 4x + 1, find a, b and c.
    Answer with full solution
    1. Add P(x) and Q(x). A plus sign in front: just remove the brackets:
      3x3 + ax2 − 5x + 2 + bx3 − 4x2 + cx − 1
    2. Collect the like terms:
      = (3 + b)x3 + (a − 4)x2 + (c − 5)x + 1
    3. Compare with 5x3 + 2x2 + 4x + 1:
      x3: 3 + b = 5 → b = 2
      x2: a − 4 = 2 → a = 6
      x: c − 5 = 4 → c = 9
      constant: 1 = 1 ✓ (no unknown here)
    4. Check:
      (3 + 2)x3 + (6 − 4)x2 + (9 − 5)x + 1 = 5x3 + 2x2 + 4x + 1 ✓
    a = 6, b = 2, c = 9

Level 2 · Core

  1. Find a and b so that (x + 2)(x2 + ax + b) = x3 + 5x2 + 8x + 4.
    Answer with full solution
    1. Multiply each term of the first bracket by the second bracket:
      (x + 2)(x2 + ax + b) = x(x2 + ax + b) + 2(x2 + ax + b)
      = x3 + ax2 + bx + 2x2 + 2ax + 2b
    2. Collect the like terms:
      = x3 + (a + 2)x2 + (b + 2a)x + 2b
    3. Compare with x3 + 5x2 + 8x + 4. Use the equations that contain one unknown first:
      x2: a + 2 = 5 → a = 3
      constant: 2b = 4 → b = 2
    4. Check with the equation we did not use (the x term):
      b + 2a = 2 + 6 = 8 ✓
    a = 3, b = 2
  2. Find a and b so that the polynomial (a − 2)x3 + (b + 1)x2 + 5x − 3 has degree 1.
    Answer with full solution
    1. A polynomial has degree 1 when the highest power that really appears is x. So the coefficients of x3 and x2 must be 0, and the coefficient of x (which is 5) is not 0.
    2. Set those two coefficients equal to 0:
      x3: a − 2 = 0 → a = 2
      x2: b + 1 = 0 → b = −1
    3. Check: the polynomial becomes
      0·x3 + 0·x2 + 5x − 3 = 5x − 3, of degree 1 ✓
    a = 2, b = −1

Level 3 · Advanced

  1. Let P(x) = x2 + ax − 2 and Q(x) = x + b. If P(x) · Q(x) = x3 + 2x2 − 5x − 6, find a and b.
    Answer with full solution
    1. Multiply every term of P(x) by every term of Q(x):
      (x2 + ax − 2)(x + b)
      = x3 + bx2 + ax2 + abx − 2x − 2b
    2. Collect the like terms:
      = x3 + (a + b)x2 + (ab − 2)x − 2b
    3. Compare with x3 + 2x2 − 5x − 6. Start with the constant term, which has only one unknown:
      constant: −2b = −6 → b = 3
      x2: a + b = 2 → a + 3 = 2 → a = −1
    4. Check with the x term:
      ab − 2 = (−1)(3) − 2 = −5 ✓
    a = −1, b = 3
  2. The polynomial P(x) = x2 + ax + b satisfies (x − 1)P(x) = x3 + 2x2 − x − 2. Find a and b, and write P(x).
    Answer with full solution
    1. Multiply (x − 1) by each term of P(x):
      (x − 1)(x2 + ax + b) = x3 + ax2 + bx − x2 − ax − b
    2. Collect the like terms:
      = x3 + (a − 1)x2 + (b − a)x − b
    3. Compare with x3 + 2x2 − x − 2:
      x2: a − 1 = 2 → a = 3
      constant: −b = −2 → b = 2
    4. Check with the x term:
      b − a = 2 − 3 = −1 ✓
    5. Write P(x):
      P(x) = x2 + 3x + 2
    a = 3, b = 2, P(x) = x2 + 3x + 2
  3. For which value of k is the polynomial (k2 − 4)x3 + (k + 2)x2 + x of degree 2?
    Answer with full solution
    1. For degree 2 the coefficient of x3 must be 0, and the coefficient of x2 must not be 0.
    2. Make the x3 coefficient zero:
      k2 − 4 = 0
      (k − 2)(k + 2) = 0 → k = 2 or k = −2
    3. Test each value in the x2 coefficient k + 2:
      k = 2: k + 2 = 4 ≠ 0 ✓ (the polynomial is 4x2 + x, of degree 2)
      k = −2: k + 2 = 0 ✗ (the polynomial would be just x, of degree 1)
    k = 2

6Sum of coefficients: the value P(1)

Remember
  • The sum of the coefficients of a polynomial P(x) is P(1): put x = 1 everywhere. For example P(x) = 2x² − 3x + 5 has coefficients 2, −3, 5 with sum 4, and P(1) = 2 − 3 + 5 = 4.
  • The constant term of P(x) is P(0).
  • For sums and products: (P + Q)(1) = P(1) + Q(1) and (P · Q)(1) = P(1) · Q(1), so you never need to expand.

Use P(1) and P(0)

  1. Find the sum of the coefficients of P(x) without expanding: P(x) = 3x4 − 2x3 + 5x − 7
    Answer
    Sum of coefficients = P(1) = −1
    P(1) = 3 − 2 + 5 − 7 = −1
  2. Find the sum of the coefficients of P(x) without expanding: P(x) = (2x − 1)5(x + 2)3
    Answer
    Sum of coefficients = P(1) = 27
    P(1) = (2−1)⁵ · (1+2)³ = 1 · 27 = 27
  3. Find the sum of the coefficients of P(x) without expanding: P(x) = (3x2 − 2x − 1)4
    Answer
    Sum of coefficients = P(1) = 0
    P(1) = (3 − 2 − 1)⁴ = 0⁴ = 0
  4. Let P(x) = x2 − 3x + 4 and Q(x) = 2x3 + x − 5. Find the sum of the coefficients of P(x) + Q(x) and of P(x) · Q(x), without expanding.
    Answer
    P(1) = 1 − 3 + 4 = 2 and Q(1) = 2 + 1 − 5 = −2. Sum of coefficients of P + Q: 2 + (−2) = 0. Of P · Q: 2 · (−2) = −4.
  5. The polynomial P(x) = ax3 + (a + 1)x2 − 4x + 2 has coefficients with sum 9. Find a.
    Answer
    P(1) = a + (a+1) − 4 + 2 = 2a − 1. Setting 2a − 1 = 9 gives a = 5. (Check: 5x³ + 6x² − 4x + 2, and 5 + 6 − 4 + 2 = 9 ✓.)
  6. The polynomial P(x) = (x + 1)n has coefficients with sum 64. Find n.
    Answer
    P(1) = 2n = 64 = 2⁶, so n = 6.
  7. Find the constant term of P(x) = (x − 2)3(x + 3)2 without expanding.
    Answer
    The constant term is P(0) = (−2)³ · 3² = −8 · 9 = −72.

11Extra note: Pascal's triangle and the binomial theorem

Remember
  • This note goes beyond the school textbook. Row n of Pascal's triangle gives the coefficients in the expansion of (a+b)n.
  • (a+b)4 = a4 + 4a3b + 6a2b2 + 4ab3 + b4  (row 4: 1, 4, 6, 4, 1). The powers of a go down from n to 0, the powers of b go up from 0 to n.
  • For (a−b)n the signs alternate: +, −, +, −, …  For example (x−1)4 = x4 − 4x3 + 6x2 − 4x + 1.
  • With a number in place of b, multiply each coefficient by the right power of that number: (x+2)4 = x4 + 4·2x3 + 6·4x2 + 4·8x + 16 = x4 + 8x3 + 24x2 + 32x + 16.
  • Binomial theorem: (a+b)n = C(n,0)an + C(n,1)an−1b + C(n,2)an−2b2 + … + C(n,n)bn, where C(n,k) = n! / (k!(n−k)!) is the k-th number in row n (counting from k = 0).

12Extra: proofs and number theory

Remember
  • To prove a statement for every integer, work with a letter (n, a, b) and use identities to reach a form such as 8n or 4(…)(…).
  • Useful facts: of two consecutive integers one is even; of three consecutive integers one is a multiple of 3; an even number is 2k, an odd number is 2k+1.

Show that…

  1. Show that (n+2)2 − (n−2)2 is a multiple of 8 for every integer n.
    Answer
    (n² + 4n + 4) − (n² − 4n + 4) = 8n.
  2. Show that (3n+2)2 − (3n−2)2 is a multiple of 24 for every integer n.
    Answer
    (9n² + 12n + 4) − (9n² − 12n + 4) = 24n.
  3. Show that (n+1)3 − (n−1)3 − 2 is a multiple of 6 for every integer n.
    Answer
    (n³ + 3n² + 3n + 1) − (n³ − 3n² + 3n − 1) − 2 = 6n² + 2 − 2 = 6n².
  4. Show that the sum of three consecutive integers is a multiple of 3. Is the sum of four consecutive integers always a multiple of 4?
    Answer
    (n−1) + n + (n+1) = 3n. For four: n + (n+1) + (n+2) + (n+3) = 4n + 6 = 4(n+1) + 2, which leaves remainder 2, so it is never a multiple of 4.
  5. Show that a two-digit number minus the number with its digits reversed is a multiple of 9. (Digits a and b: the number is 10a + b.)
    Answer
    (10a + b) − (10b + a) = 9a − 9b = 9(a − b).
  6. Show that every four-digit number of the form abab (for example 3737) is a multiple of 101.
    Answer
    1000a + 100b + 10a + b = 1010a + 101b = 101(10a + b). (Check: 3737 = 101 · 37.)
  7. Show that the square of any odd number leaves remainder 1 when divided by 8.
    Answer
    (2n+1)² = 4n² + 4n + 1 = 4n(n+1) + 1. The product n(n+1) of two consecutive integers is even, n(n+1) = 2k, so (2n+1)² = 8k + 1.
  8. Show that the difference of the squares of two odd numbers is a multiple of 8.
    Answer
    (2a+1)² − (2b+1)² = 4a² + 4a − 4b² − 4b = 4[(a−b)(a+b) + (a−b)] = 4(a−b)(a+b+1). The two factors (a−b) and (a+b+1) add up to 2a+1, an odd number, so one of them is even. Hence the product is a multiple of 4 · 2 = 8.
  9. Show that n3 − n is a multiple of 6 for every integer n.
    Answer
    n³ − n = n(n² − 1) = (n−1)n(n+1), three consecutive integers. One of them is a multiple of 3 and at least one is even, so the product is a multiple of 6.
  10. Show that a2 + b2 ≥ 2ab for all real numbers a and b. When does equality hold?
    Answer
    a² + b² − 2ab = (a − b)² ≥ 0, so a² + b² ≥ 2ab. Equality holds exactly when a = b.
  11. Show that n2 + (n+1)2 + (n(n+1))2 is a perfect square. (Try n = 2: 4 + 9 + 36 = 49.)
    Answer
    n² + (n² + 2n + 1) + (n⁴ + 2n³ + n²) = n⁴ + 2n³ + 3n² + 2n + 1 = (n² + n + 1)². (For n = 2: 7² = 49.)
  12. Show that n(n+1)(n+2)(n+3) + 1 is a perfect square. (Try n = 1: 1·2·3·4 + 1 = 25.)
    Answer
    n(n+3) · (n+1)(n+2) + 1 = (n²+3n)(n²+3n+2) + 1. Put m = n²+3n: m(m+2) + 1 = m² + 2m + 1 = (m+1)² = (n²+3n+1)². (For n = 1: 5² = 25.)
  13. Show that n4 + 4 is not a prime number for any integer n > 1. (Hint: add and subtract 4n2.)
    Answer
    n⁴ + 4 = (n⁴ + 4n² + 4) − 4n² = (n²+2)² − (2n)² = (n² − 2n + 2)(n² + 2n + 2). For n > 1 the first factor (n−1)² + 1 is at least 2 and the second is larger than 2, so n⁴ + 4 is a product of two numbers greater than 1. (For n = 2: 20 = 2 · 10.)
